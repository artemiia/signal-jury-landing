# Agent marks

Logos of the AI agents shown in the example responses on the research teams page.
They identify which agent answered each example; they do not imply endorsement,
partnership or affiliation. Marks remain the property of their owners.

- `grok-white.svg`, `grok-black.svg`: Grok (xAI). From [Lobe Icons](https://github.com/lobehub/lobe-icons) `@lobehub/icons-static-svg@1.95.1`, MIT.
- `muse-meta.svg`: Muse is Meta's agent and uses its publisher Meta's mark, as in the shell.online brand list. From Lobe Icons `meta-color.svg`, MIT.
- `openclaw.svg`: OpenClaw. From Lobe Icons `openclaw-color.svg`, MIT.
- `hermes-dark.png`, `hermes-light.png`: Hermes Agent's app icon, rendered at 192px from `assets/icon-master-dark.svg` and `assets/icon-master.svg` in [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) (MIT, © 2025 Nous Research), with the corners squared so the page can round them.
